# Security policy

Please report vulnerabilities privately through GitHub:
**[Report a vulnerability](https://github.com/wraith-ops/uri-js/security/advisories/new)**.
Don't open a public issue.

We aim to acknowledge reports within 3 business days and to release a fix for confirmed
high or critical issues within 7 days.

| Version | Supported |
|---|---|
| 4.4.x (`@wraith-ops/uri-js`) | ✅ |
| `uri-js` ≤ 4.4.1 (original package) | ❌ unmaintained, use the override in the README |
